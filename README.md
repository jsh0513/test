# 货运司机任务分派管理系统

基于 **Vue 3 + Express** 的前后端分离后台管理系统，面向货运调度场景，覆盖任务从**创建 → 定时发布 → 派发司机 → 确认发车 → 运输中 → 确认完成 → 历史归档**的完整生命周期，并配套司机管理、人员变动审核、数据统计与报表导出能力。

---

## 功能特性

### 数据概览
- 本月任务量、司机规模等关键指标卡片
- 任务状态分布、司机状态占比图表（ECharts）

### 任务发布（仅超级管理员）
- 创建任务草稿：装货/卸货地点、货物类型、重量、完成期限、最迟截止时间、运费、备注、加急标记
- 草稿支持 **立即发布**、**查看/修改**、**定时发布**，并支持 **多选批量发布**
- 定时发布区按发布时间升序排列，到点由后端自动发布并进入派发中心
- 最迟截止时间、货物类型等关键字段为必填项

### 任务派发与跟踪
- 按任务编号、起终点、状态筛选
- 点击状态标签推进任务：`待派发 → 待发车（选司机）→ 进行中（确认发车）`
- 派发面板按距离与车型推荐司机，支持按车型、当前所在地搜索
- **最迟发车倒计时 / 任务倒计时** 响应式实时刷新，归零后转为超时计时
- 距最迟发车或任务截止不足 1 小时时，操作列显示三角预警图标
- 搜索栏右侧统计待派发、待发车、进行中、已超时四类任务数量

### 历史任务
- 已完成 / 已取消任务归档，支持编号、起终点、时间范围查询
- 详情展示基本信息、时间信息、其他信息三段内容
- 支持管理员切换「发车是否超时」「任务是否超时」「是否加急」标记，调度员只读
- 全流程操作日志：创建、修改、派发、发车、确认完成、取消均记录操作人

### 司机管理
- 司机信息增删改查、启停用、状态维护（空闲 / 请假 / 休假 / 任务中 / 已停用 / 待审核）
- 司机详情统计：任务统计、接单历史、出勤日历、保修倒计时
- 任务完成后司机所在城市自动同步为任务目的地

### 人员变动
- 调度员提交新增司机申请，超级管理员审核通过 / 驳回
- 司机信息变更日志：记录修改前后值、操作人、操作类型

### 数据查询统计
- 任务记录导出（Excel，25 列，与历史任务详情字段对齐）
- 员工出勤记录导出（按年月或时间范围）
- 订单/运单对账表导入与导出
- 支持「下载全部」与「下载已选」

### 账号管理
- 账号新增、密码修改、角色分配
- 超级管理员与调度员权限隔离

### 其他
- 暗色 / 亮色主题切换
- 任务通知、附件与运输照片上传（base64 存储）

## 快速开始

### 环境要求
- Node.js >= 18
- npm >= 9
- MySQL 8.x（可选，未配置时自动使用内存 Mock 数据）

### 1. 启动后端

```bash
cd backend
npm install
npm start
```

启动成功后监听 `http://localhost:3001`，健康检查：`GET /api/health`。

### 2. 启动前端

```bash
cd frontend
npm install
npm run dev
```

访问 `http://127.0.0.1:5174`，前端通过 Vite 代理将 `/api` 转发至 `http://localhost:3001`。

### 3. 生产构建

```bash
cd frontend
npm run build      # vue-tsc 类型检查 + vite build，产物在 dist/
npm run preview
```

## 核心业务规则

### 任务状态流转

```
待派发 ──派发──> 待发车 ──确认发车──> 进行中 ──确认完成──> 已完成
   │                  │                 │
   └──────────────────┴─────────────────┴──> 取消 ──> 已取消
                      └── 超过截止时间 ──> 已超时
```

- **最迟发车时间**：创建任务时由管理员填写，未按时发车记为「发车超时」
- **任务截止时间** = 派发时间 + 完成期限（SLA 小时）
- **任务超时**：超过截止时间未完成记为「任务超时」，超时后继续计时直至确认完成
- 超时标记一经产生即持久保存，管理员可在历史任务中手动修正

### 时间字段说明

| 字段 | 含义 |
| --- | --- |
| 发布时间 | 任务正式发布的时间 |
| 派发时间 | 确认执行司机的时间 |
| 发车时间 | 点击「确认发车」的时间 |
| 任务截止时间 | 派发时间 + 完成期限 |
| 完成时间 | 确认完成并提交运输照片的时间 |

### 司机状态

`空闲` / `请假` / `休假` / `任务中` / `已停用` / `待审核`

- 未审核司机不能接单
- 任务执行中的司机自动置为「任务中」，且不可再派新任务
- 任务确认完成后恢复「空闲」，所在城市同步为任务目的地

## 数据说明

后端启动时会尝试连接 MySQL：

- **连接成功**：读取 MySQL 中的业务数据
- **连接失败**：自动降级为**内存 Mock 数据**，控制台输出 `[DB] 未连 MySQL，使用内存 Mock`

内存模式下所有增删改在服务重启后重置，适合本地演示与功能验证。

## 常见问题

**端口被占用**

后端会提示 `EADDRINUSE` 并给出占用进程 PID，可执行：

```bash
netstat -ano | findstr :3001
taskkill /PID <PID> /F
```

前端固定使用 5174 端口（`strictPort: true`），端口被占用时启动会直接报错而不会自动切换端口。

**附件上传报 `request entity too large`**

`server.js` 已将 JSON 请求体上限调整为 `25mb` 以支持多张 base64 图片上传，如仍失败请检查图片体积。

**页面空白**

检查后端是否已启动，以及浏览器控制台是否有接口 401/跨域报错。
